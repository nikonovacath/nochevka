# Ночёвка

Игры из детства. Дань ностальгии, семье и детству.

- `index.html` — главная с выбором игры
- `ugolki/` — «Уголки», дедушкина игра на шахматной доске
- `vishibali/` — «Вышибалы», в простонародье «Чапаев»

Каждая игра — один файл `index.html` со своими картинками и звуками рядом. Онлайн-режим работает через Firebase, правила базы для всех игр лежат в `database.rules.json`: их вставляют в консоль Firebase целиком.
